# 图书管理系统 README
## 一、项目介绍
本项目为纯前端的图书管理系统，纯前端轻量化校园图书管理系统，基于 HTML5 + CSS3 + 原生 JavaScript 三层分离开发，不依赖后端、数据库、服务器，依靠浏览器 LocalStorage 实现数据本地持久化，完整覆盖试卷四大考核任务全部功能需求。

## 二、文件结构
```
图书管理系统/
├─ index.html    # 页面结构文件，承载所有页面DOM、弹窗、表格
├─ style.css     # 独立样式文件，全局布局、按钮、表格、弹窗美化
└─ main.js       # 业务逻辑文件，处理数据、交互、筛选、存储
```

## 三、环境运行方式
1. 将三个文件放置在**同一文件夹**内；
2. 直接双击 `index.html`，使用任意浏览器打开即可运行；
3. 刷新/关闭页面数据不会丢失，数据存储在浏览器本地缓存；
4. 推荐 Chrome、Edge 浏览器，兼容性最佳。

## 四、核心功能（对应考核任务）
### 任务一：图书基础增删改管理
1. 新增图书：弹窗填写图书信息、存放位置，表单重置、提交自动刷新列表；
2. 编辑图书：点击编辑自动回填原有数据，修改后覆盖原记录；
3. 删除图书：弹出确认提示，确认后永久删除数据；
4. 表单校验：书名、作者、存放位置为必填项。

### 任务二：借阅时间与状态管理
1. 支持录入借阅日期、归还日期，格式为标准日期控件；
2. 三种图书状态：在馆、已借出、逾期未还，不同颜色区分展示；
3. 自动计算并展示借阅间隔天数；
4. 单独筛选今日到期图书，实现到期提醒。

### 任务三：视图切换与检索
1. 三类视图切换：全部图书 / 已借出图书 / 今日到期图书；
2. 书名关键词模糊搜索，视图+关键词双重过滤；
3. 无数据、无搜索结果时展示友好空白提示；
4. 顶部统计卡片实时展示图书总数、在馆、借出、逾期数量。

## 五、技术说明
1. 结构：HTML5 语义化布局，页面、弹窗、表格分层搭建；
2. 样式：独立 CSS 文件，后台管理系统风格，hover、弹窗遮罩、状态色彩区分；
3. 脚本：原生 JS，无第三方插件，封装本地存储、数据筛选、日期计算；
4. 数据持久化：LocalStorage 将图书数据存入浏览器本地。
## 六、使用注意事项
1. 文件不可拆分放置不同文件夹，否则样式、JS 加载失效；
2. 浏览器缓存异常时，按 `Ctrl+F5` 强制刷新；
3. 清空浏览器 LocalStorage 会重置所有图书数据，恢复初始测试数据；
4. 仅适配电脑端浏览，未做移动端适配。
